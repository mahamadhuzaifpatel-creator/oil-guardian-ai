# Report Type Labelling Guide

Use these rules, in this order, for every report (training data, test data, and officer confirmation).

| Question | If yes → |
|---|---|
| 1. Did someone get **hurt**, or was anything **damaged / spilled / burnt**? | **Incident** |
| 2. Did an **event happen** (something fell, released, slipped, caught fire, collided) that **could have** hurt someone, but nobody was hurt and nothing significant was damaged? | **Near Miss** |
| 3. No event. Was a **person seen doing** something unsafe (behaviour, skipped control, no permit, no PPE, bypass)? | **Unsafe Act** |
| 4. No event. Is something **physical** unsafe (equipment, area, material, missing guard, leak, corrosion, broken)? | **Unsafe Condition** |

Tie-breakers
- A near miss caused by an unsafe act is still a **Near Miss** (an event happened).
- "Found a leak" with nothing else happening is an **Unsafe Condition**; "the leak caught fire" is an **Incident** (fire damage) or **Near Miss** (put out immediately, no damage).
- Report type does **not** decide SIF potential. A low-severity incident can be non-SIF; an unsafe act can be SIF.

Examples
- "Welder cutting pipeline without hot work permit" → Unsafe Act
- "Handrail on tank stair corroded and broken" → Unsafe Condition
- "Spanner fell from monkey board, landed near floorman, nobody hurt" → Near Miss
- "Floorman's finger crushed by slips, taken to hospital" → Incident
